# Clinic-Management-System

### المميزات:**إدارة المواعيد:** حجز وتنظيم مواعيد زيارة المرضى للعيادة.
* **سجلات المرضى:** حفظ وتحديث بيانات المرضى وتاريخهم الطبي.
* **سهولة الاستخدام:** واجهة بسيطة وواضحة لتسهيل الإدارة اليومية.

### التقنيات المستخدمة:
* **لغة البرمجة:** Python
* **قاعدة البيانات:** SQLite
